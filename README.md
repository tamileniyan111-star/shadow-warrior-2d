# Shadow Warrior 2D

A fully playable 2D side-scrolling adventure platformer designed for desktop and Android-style mobile play.

## Features
- Side-scrolling platform gameplay with run, jump, and attack
- Three themed levels: forest, cave, and castle
- Coins, health bar, score system, and multiple enemy types
- Boss battle at the final castle stage
- Main menu, pause menu, and game over screen
- Touch controls for mobile devices
- Procedural audio effects and music generated in-browser
- HD-inspired pixel-art style with smooth motion and responsive controls

## How to run
1. Open `index.html` in a browser, or
2. Serve the folder with a simple local web server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Controls
- Move: A / D or Left / Right arrows
- Jump: W / Up / Space
- Attack: J / K / Enter
- Pause: P

## Mobile controls
- Touch buttons are shown on-screen for Left, Right, Jump, and Attack.

## Notes
This game is intentionally self-contained and uses no external assets or dependencies, making it easy to run anywhere a modern browser is available.
